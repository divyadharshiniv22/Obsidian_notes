## Interview Question

**Q:** When would you choose Django over FastAPI?

**Answer:** Choose Django when building a complete web application that needs features like authentication, an admin panel, templates, and a built-in ORM.

**Q:** When would you choose FastAPI over Django?

**Answer:** Choose FastAPI when building high-performance REST APIs, microservices, or AI/ML services where speed, automatic validation, async support, and interactive API documentation are important.

# Why `.get()`?

HTTP has different request methods.

|Method|Purpose|Example|
|---|---|---|
|GET|Retrieve data|Get all users|
|POST|Create data|Create a user|
|PUT|Update all data|Replace a user|
|PATCH|Update part of data|Change a user's email|
|DELETE|Delete data|Remove a user|
