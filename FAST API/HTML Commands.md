### 2. Learn tags by purpose

| What you want | Tag        | Easy memory             |
| ------------- | ---------- | ----------------------- |
| Heading       | `<h1>`     | **h = heading**         |
| Paragraph     | `<p>`      | **p = paragraph**       |
| Link          | `<a>`      | **a = anchor**          |
| Image         | `<img>`    | **img = image**         |
| Button        | `<button>` | **button = button**     |
| List          | `<ul>`     | **ul = unordered list** |
| List item     | `<li>`     | **li = list item**      |
| Form          | `<form>`   | **form = form**         |
| Input         | `<input>`  | **input = input**       |
| Table         | `<table>`  | **table = table**       |
### 🧠 Easy way to remember

**U = Unordered**  
**L = List**

So:

```
<ul>
    <li>Apple</li>
    <li>Banana</li>
    <li>Mango</li>
</ul>
```

It displays as:

- Apple
- Banana
- Mango

### Important

`<ul>` = creates the **list**  
`<li>` = creates each **list item**

## 🔗 Links

Use `<a>` to create a link.

```
<a href="https://google.com">Google</a>
```

Here:

```
<a>       → link
href      → where the link goes
Google    → text user sees
```
