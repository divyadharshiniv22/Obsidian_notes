| Command  | Simple meaning                                | Example                |
| -------- | --------------------------------------------- | ---------------------- |
| `pwd`    | Shows **where you are**                       | `pwd`                  |
| `ls`     | Shows **files/folders**                       | `ls`                   |
| `cd`     | **Move** to another folder                    | `cd project`           |
| `mkdir`  | **Create a folder**                           | `mkdir backend`        |
| `touch`  | **Create an empty file**                      | `touch main.py`        |
| `cp`     | **Copy** a file/folder                        | `cp a.txt b.txt`       |
| `mv`     | **Move or rename**                            | `mv old.py new.py`     |
| `rm`     | **Delete**                                    | `rm file.txt`          |
| `cat`    | **Display file content**                      | `cat main.py`          |
| `less`   | Read a **large file page by page**            | `less app.log`         |
| `head`   | Show **beginning** of file                    | `head app.log`         |
| `tail`   | Show **end** of file                          | `tail app.log`         |
| `grep`   | **Search text**                               | `grep "error" app.log` |
| `find`   | **Find files/folders**                        | `find . -name "*.py"`  |
| `chmod`  | Change **permissions**                        | `chmod +x script.sh`   |
| `ps`     | Show **running processes**                    | `ps aux`               |
| `kill`   | **Stop a process**                            | `kill 1234`            |
| `ss`     | Show **network/ports**                        | `ss -tuln`             |
| `curl`   | Send **HTTP requests**                        | `curl localhost:8000`  |
| `echo`   | **Print text/value**                          | `echo "Hello"`         |
| `export` | Create/set an **environment variable**        | `export PORT=8000`     |
| `sudo`   | Run command with **administrator privileges** | `sudo apt update`      |
| `apt`    | **Install/manage software** on Ubuntu/Debian  | `sudo apt install git` |
| `ssh`    | **Connect to a remote computer/server**       | `ssh user@server`      |
