## Comparison Operators

| Operator | Meaning          |
| -------- | ---------------- |
| `==`     | Equal            |
| `!=`     | Not equal        |
| `>`      | Greater than     |
| `<`      | Less than        |
| `>=`     | Greater or equal |
| `<=`     | Less or equal    |

---

## Logical Operators

|   |   |
|---|---|
|Operator|Meaning|
|`and`|Both conditions true|
|`or`|At least one true|
|`not`|Opposite condition|
