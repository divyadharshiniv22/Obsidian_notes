## Getter and Setter in Python — Simple Explanation

A **getter** is used to **get/read a value** from an object.

A **setter** is used to **set/update a value**, often with **validation**.

## Easy Table

| Getter                   | Setter                             |
| ------------------------ | ---------------------------------- |
| Gets (reads) the value   | Sets (updates) the value           |
| Uses `@property`         | Uses `@property_name.setter`       |
| Returns a value          | Assigns a value                    |
| Example: `student.house` | Example: `student.house = "ambur"` |
## Easy Memory Trick

- **Getter → GET → Read**
- **Setter → SET → Update**
