# What is a Decorator?

A **decorator** is a function that **adds extra behavior to another function without changing its original code**.

Think of it like this:

> **Decorator = Add something extra to a function.**

# Real-life Example

Imagine you buy a plain cake.

🍰 Cake

Now you add chocolate.

🍫 + 🍰 = Chocolate Cake

Did you change the cake?

❌ No.

You only **added something extra**.

A decorator works the same way.
> 
> **Why do we use decorators?**

A good answer is:

> "Decorators are used to add extra functionality to a function without modifying its original code. They help avoid code duplication and make the code cleaner and easier to maintain."
