### Easy Definition for Interview

> Validating attributes means checking whether the values assigned to an object's attributes are correct before storing them. This prevents invalid data from being stored in the object.

### Memory Trick

```
Validation = Check first → Store later
```

Example:

```python
Age = -5      ❌ Reject
Age = 22      
✅ Store
House = ABC   ❌ Reject
House = Ravenclaw 
✅ Store
```
