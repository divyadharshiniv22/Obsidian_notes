
## Multiple Arguments – Simple Way

### Basic Idea

You can print multiple things together by using a **comma** `**,**`.

```
name = input("What's your name? ")
print("Hello,", name)
```

👉 Output:

```
Hello, David
```

---

### Easy Rules to Remember

- Use **comma** `**,**` → Python adds a **space automatically**
- No need to use `+` for beginners
- Keep it simple

---

### One-Line Trick (Best for Beginners ⭐)

```
print("Hello,", input("What's your name? "))
```

---

### Very Simple Summary

- `,` → joins values with space
- `+` → joins strings manually
- Best simple way → use **comma**

---

If you’re just starting, **always use comma** — it’s the easiest and safest.
