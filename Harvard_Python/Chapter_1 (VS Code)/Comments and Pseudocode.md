## Comments

Example:

```python
# Ask the user for their name
name = input("What's your name? ")

# Print a greeting
print("Hello,", name)
```

Comments help programmers:

- Understand the logic of the program
    
- Remember why certain decisions were made
    
- Make code easier for others to read and maintain

### Pseudocode

**Pseudocode** is an informal way of writing the steps of a program using plain language before writing the actual code. It helps programmers think through the logic of a solution.

Example pseudocode for a greeting program:

```
Ask the user for their name
Store the name in a variable
Display "Hello" followed by the user's name
```

After writing pseudocode, it can be converted into actual Python code:

```
name = input("What's your name? ")
print("Hello,", name)
```

Using **pseudocode** helps in planning the program first, while **comments** help explain the program after it is written.
