# Bugs and Debugging

## What is a Bug?
- A **bug** is a mistake in a program, and it can take many forms.
- Everyone makes mistakes while coding; even experienced programmers still encounter bugs.
- Bugs are simply **problems to solve**, and with time, practice, and experience, fixing them becomes easier.

---

## Learning Perspective
- Do not get discouraged if your program does not work the first time.
- Over time, you will learn both **mental strategies** and **technical tools** to solve programming problems.
- Debugging is an essential part of the learning process.

---

## Example: Small Syntax Mistake
Sometimes the code is **99% correct**, but a small missing detail causes an error.

Example (missing closing parenthesis):

```python
print("hello, world"
```

When running:

python hello.py
Python shows an error called a SyntaxError, because the closing ) is missing.
# Bug vs Debugging

## Definitions

- **Bug**: An error, flaw, or defect in a program that causes incorrect behavior.
    
- **Debugging**: The process of identifying, analyzing, and fixing error

    

---

## Comparison

|Aspect|Bug|Debugging|
|---|---|---|
|Meaning|Error, flaw, or defect in a program|Process of finding and fixing errors|
|Nature|Problem (mistake in code)|Process (method used to solve the problem)|
|Example|Missing parenthesis, wrong variable value|Reading error messages, checking variables, correcting code|
|When it occurs|During program writing or execution|After a bug is detected|
|Goal|Causes incorrect output or program failure|Restores correct functioning of the program|

---

## Summary

- **Bug = mistake in the program**
    
- **Debugging = process of finding and fixing the mistake**
